# bbob

이틀 연속 러닝을 쉬면, 벌칙 하나. 타로 카드 한 장을 골라 벌칙을 확인하는 미니멀한 뽑기 앱입니다.

[bbob — 러닝 약속](https://bbkk-ivory.vercel.app/)

상·중·하·극하 탭에서 모두가 함께 쓰는 벌칙 목록을 편집합니다. 러닝 여부는 직접 판단하며 운동 기록이나 달력 기능은 제공하지 않습니다.

| 등급 | 확률 | 카드 앞면 | 기본 벌칙 |
| --- | --- | --- | --- |
| 상 | 60% | 흰색 | 청소 20분, 설거지 전담 |
| 중 | 35% | 파란색 | 친구에게 커피 사기 |
| 하 | 4.9% | 금색 | 배달 대신 직접 요리 |
| 극하 | 0.1% | 빛나는 금색 | 미뤄둔 일 30분 |

## 기능

- 네 등급 탭에서 항목 이름 입력, 추가·수정·삭제
- 브라우저·기기 간 공유 목록 자동 저장과 변경 동기화
- 고정 확률로 등급 추첨 후 해당 등급 안에서 균등 선택
- Web Crypto 난수 기반 카드 뽑기와 클릭 공개
- 다섯 장의 내용을 미리 정하고 선택 후 나머지 카드까지 공개
- 당첨 항목 제외 옵션과 뽑기 기록
- 개인 브라우저에 설정·기록·아직 열지 않은 카드 저장
- 공개된 카드와 선택 위치도 보관하며 당첨 기록은 선택한 한 장만 추가
- 모바일·데스크톱 대응과 모션 감소 설정 지원

어느 등급이든 항목이 비거나 당첨 제외로 소진되면 뽑기를 잠시 막습니다. 해당 등급에 항목을 추가하거나 전체 항목을 다시 포함하면 계속할 수 있습니다. 이때도 등급 확률은 바뀌지 않습니다.

목록은 사이트를 사용하는 모두에게 공유됩니다. `공유됨`은 저장 완료 상태이며, 연결·저장 중에는 새 뽑기가 잠시 비활성화됩니다. 충돌 시 `최신 목록`과 `내 수정 적용` 중 선택하고, 연결 실패 시 `다시 연결`로 복구합니다. 이미 뽑은 카드와 개인 기록은 다른 사용자의 편집에 영향을 받지 않습니다.

## 로컬 실행

Node.js 24와 npm을 사용합니다.

```sh
git clone https://github.com/Heedo-Kim0624/bbkk.git
cd bbkk
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소를 엽니다. 기본 주소는 `http://127.0.0.1:5173`입니다. Windows PowerShell 실행 정책으로 `npm` 명령이 차단되면 `npm.cmd`를 사용합니다.

로컬 앱도 `src/config/shared.ts`에 설정된 공유 목록에 연결합니다. 자동 브라우저 테스트는 페이지별 모의 RPC를 사용하므로 실제 공유 목록을 수정하지 않습니다.

## 검증 및 빌드

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm run preview
```

프로덕션 산출물은 `dist/`에 생성됩니다. 검증 결과는 `docs/progress.md`에 실제 실행 기준으로 기록하며, 실행하지 않은 항목은 통과로 간주하지 않습니다.

Windows에서는 다음 검증 스크립트가 lint, 타입 검사, 단위 테스트, 프로덕션 빌드를 순서대로 실행하고 실패 시 중단합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify.ps1
```

브라우저 테스트를 처음 실행하기 전에는 Chromium을 설치합니다.

```sh
npx playwright install chromium
npm run test:e2e
```

전체 검증 스크립트에 Playwright 브라우저 테스트까지 포함하려면 `-WithBrowser`를 추가합니다. 브라우저 테스트 실행 환경과 검증 범위는 `docs/verification.md`를 참고합니다.

## Vercel 배포

1. Vercel에서 **Add New → Project**를 선택하고 `Heedo-Kim0624/bbkk` 저장소를 가져옵니다.
2. 프로젝트 루트는 이 폴더를 선택합니다. 프레임워크는 **Vite**, Node.js는 **24.x**를 사용합니다.
3. `vercel.json`의 설치 명령 `npm ci`, 빌드 명령 `npm run build`, 출력 폴더 `dist` 설정을 확인합니다. 환경 변수는 필요하지 않습니다.
4. 배포 후 두 브라우저의 목록 동기화, 카드 뽑기·공개, 새로고침 복원과 모바일 화면을 확인합니다. 동기화 확인용으로 만든 항목만 제거하여 기존 사용자 편집을 보존합니다.

`.vercelignore`는 로컬 에이전트 기록과 문서·검증 산출물을 업로드에서 제외합니다. 이 저장소에 배포 설정이 있다는 사실은 실제 배포 완료를 의미하지 않습니다. 계정 연결 및 공개 배포는 프로젝트의 승인 경계를 따릅니다.

## 기술 구성

React 19 · TypeScript · Vite · Astryx Design System · Lucide · Vitest · Supabase Postgres. Astryx는 패키지의 사전 빌드 CSS와 neutral 테마를 사용합니다. 공유 API는 Supabase의 제한된 공개 RPC를 사용하며 공개 클라이언트 설정은 `src/config/shared.ts`에 있습니다.

벌칙 항목은 서버에 공유되지만 사용자 설정·당첨 제외·기록·아직 열지 않은 카드는 현재 브라우저에만 보관됩니다. 브라우저 데이터를 지우면 개인 데이터는 사라집니다. 공유 목록이 오프라인이어도 이미 뽑은 카드는 열 수 있습니다. 이전 기기 전용 목록은 자동 업로드하지 않고 보존하며, 도움말의 `이 기기의 목록 가져오기`로 공유 목록에 추가할 수 있습니다. 목록 초기화는 모든 사용자에게 반영됩니다.

제품 요구사항은 `docs/prd.md`, 구조는 `docs/architecture.md`, 로컬 검증 명령은 `quality_gates.yaml`을 참고합니다.
