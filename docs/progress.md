# 작업 진행 기록

## 2026-09-23 — 첫 구현

- JARVIS 작업 공간을 준비하고 제품 요구사항과 아키텍처를 구체화했다.
- React 19, TypeScript, Vite와 Astryx neutral 테마를 구성했다.
- 아이보리·민트 글래스모피즘 UI와 반응형 화면, 텍스트 항목 편집, 가중치 기반 뽑기, 당첨 제외, 기록과 로컬 저장을 구현했다.
- Vercel 정적 배포 설정과 한국어 실행·배포 안내를 작성했다.
- 기존 파일 존재 검사 전용 `scripts/verify.ps1`을 실제 lint·타입 검사·단위 테스트·프로덕션 빌드 검증으로 교체했다. 각 명령의 종료 코드를 검사하며 `-WithBrowser`로 브라우저 검증을 추가할 수 있다.

## 첫 구현 검증 결과

2026-09-23 최종 코드에서 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify.ps1`을 실행했으며 종료 코드는 0이었다. 브라우저 결과는 별도로 수행한 최종 Playwright 검증 보고서와 프로덕션 미리보기 검증 자료를 확인해 반영했다.

| 검증 | 결과 | 근거 |
| --- | --- | --- |
| ESLint | 통과 | `npm run lint`, 종료 코드 0 |
| TypeScript | 통과 | `npm run typecheck`, 종료 코드 0 |

최종 빌드는 앱과 React·UI 의존성을 분리한다. JS 청크는 앱 27.41 kB, React 218.84 kB, UI 276.69 kB이며 빌드 경고가 없다.

브라우저 검증은 320·390·768·1440 px 화면에서 가로 넘침과 브라우저 예외가 없는 것을 확인했다. 텍스트 추가·수정, 키보드 가중치 변경, 확률 정규화, 삭제 취소, 저장·복원, 제외 모드, 일괄 입력 검증, 애니메이션 중 중복 실행 방지를 확인했다. 모바일의 60자 당첨 결과는 화면 안에 표시되고 뽑기 버튼과 겹치지 않았다. 저장이 차단된 상황에서도 뽑기는 동작하고 보관 제한 안내가 표시됐다.

## 남은 작업과 경계

- 위 `outputs/browser/` 자료는 로컬 검증 증거이며 Git 저장소에는 포함하지 않는다. `npm run test:e2e`로 브라우저 테스트와 HTML 보고서·스크린샷을 새로 생성할 수 있다. 수동 검토 요약인 `validation.md`와 별도 프로덕션 확인 결과인 `production-smoke.json`은 해당 명령이 자동 생성하지 않는다.

- Vercel 공개 배포가 완료되어 https://bbkk-ivory.vercel.app/ 에서 서비스 중이다. 러닝 약속 변경의 재배포 상태는 아래 기록을 따른다.
- 실제 iOS Safari 기기 검증이 남아 있다. 이번 브라우저 검증은 Chromium과 모바일 크기 시뮬레이션 범위다.
- 사용자 데이터는 해당 브라우저에만 저장된다. 기기 간 동기화는 범위에 포함하지 않는다.

## 2026-09-23 — 러닝 약속으로 조정

- 사용 목적을 이틀 연속 러닝을 쉬었을 때의 벌칙 뽑기로 조정한다. 기존 디자인과 기능은 유지하고 화면 문구를 줄인다.
- 페이지 제목과 메타데이터를 `bbob — 러닝 약속`, `이틀 연속 쉬면, 벌칙 하나.`로 변경했다.
- 기본 벌칙은 청소 20분, 설거지 전담, 친구에게 커피 사기, 배달 대신 직접 요리, 미뤄둔 일 30분이며 각각 20%다.
- 사용자 항목과 기록을 보존한다. 정확히 일치하는 미사용 점심 기본 샘플만 새 벌칙 기본값으로 전환한다.
- 러닝 기록, 달력과 연속 일수 자동 판정 기능은 추가하지 않는다.
- 이번 변경의 최종 로컬 검증은 Vitest 32개, Playwright 8개, `npm run build`, `npm run lint` 모두 통과했다.
- 공개 주소는 https://bbkk-ivory.vercel.app/ 이다. 배포 상태는 GitHub의 Vercel 검사에서 확인하며, 이 커밋의 배포 후 공개 페이지 검증 결과는 로컬 review 기록과 Obsidian 작업 요약에 남긴다.
