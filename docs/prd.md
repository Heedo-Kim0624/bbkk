# bbob 제품 요구사항

## 목적

이틀 연속 러닝을 쉬었을 때 벌칙 하나를 뽑는 한국어 웹사이트. 사용자는 네 등급의 탭에서 벌칙 텍스트를 편집하고, 고정 확률로 나온 알을 눌러 결과를 확인한다. 기존 미니멀 글래스모피즘 디자인을 유지하고 화면 문구를 최소화한다. Vercel에 정적 배포한다.

## 화면과 사용 경험

- 아이보리 배경, 민트 포인트, 반투명 유리 패널을 사용하는 미니멀한 디자인.
- 데스크톱에서는 뽑기와 편집 화면을 함께 보여주고 모바일에서는 자연스럽게 세로로 배치.
- 뽑기 애니메이션 후 등급별 알을 표시하고, 알을 누르면 벌칙 하나를 공개한다.
- 상·중·하·극하 탭에서 해당 등급의 항목을 추가·수정·삭제한다.
- 등급은 색 외에도 텍스트로 구분한다. 알 공개는 키보드로도 실행할 수 있고 모션 감소 설정을 지원한다.
- 당첨 항목 제외 선택, 뽑기 기록, 브라우저 내 설정 보관.
- 페이지 제목은 `bbob — 러닝 약속`, 핵심 안내는 `이틀 연속 쉬면, 벌칙 하나.`로 짧게 표현한다.

## 기능 규칙

- 등급과 확률·알 표현은 아래 표로 고정한다. 각 등급 안에서는 뽑을 수 있는 벌칙을 균등하게 선택한다.

| 등급 | 전체 추첨 확률 | 알 표현 | 기본 벌칙 |
| --- | --- | --- | --- |
| 상 | 60% | 흰색 | 청소 20분, 설거지 전담 |
| 중 | 35% | 파란색 | 친구에게 커피 사기 |
| 하 | 4.9% | 금색 | 배달 대신 직접 요리 |
| 극하 | 0.1% | 빛나는 금색 | 미뤄둔 일 30분 |

- 항목 이름은 사용자 입력 텍스트이며 HTML로 실행하지 않는다.
- 어느 등급이든 유효한 항목이 없으면 뽑기를 막고 해당 탭에 항목을 채우도록 짧게 안내한다. 남은 등급의 확률로 재분배하지 않는다.
- 당첨 항목 제외로 한 등급의 선택지가 소진되어도 뽑기를 막는다. 항목을 추가하거나 전체 항목을 다시 포함할 수 있게 안내한다.
- 결과는 브라우저의 Web Crypto 난수로 선택한다. 애니메이션은 등급 확률과 등급 내 균등 확률에 영향을 주지 않는다.
- 알을 공개하면 벌칙과 등급을 표시하고 기록을 한 번만 추가한다. 애니메이션이나 공개 대기 중 중복 실행·설정 변경이 해당 결과를 바꾸지 않아야 한다.
- 설정·기록·공개 대기 중인 알은 해당 브라우저의 localStorage에 저장한다. 새로고침 후에도 같은 알을 이어서 공개할 수 있어야 한다. 저장이 제한된 경우 현재 탭에서 사용할 수 있고 보관 제한을 안내한다.
- 기존 사용자 항목과 기록은 보존한다. 등급이 없는 기존 사용자 항목은 상으로 옮기며, 이전 기본 벌칙은 표의 등급으로 배치한다. 기존 기록을 새로운 당첨으로 다시 기록하지 않는다.

## 범위

러닝 여부와 이틀 연속 휴식 여부는 사용자가 직접 판단한다. 운동 추적, 달력, 연속 일수 자동 계산, 로그인, 결제, 서버 데이터베이스, 기기 간 동기화는 포함하지 않는다.

## 구현 계획과 검증 경로

1. PRD와 구조 문서를 확정하고 등급 확률 경계·등급 내 균등 선택·상태 전환·기존 저장 데이터 이관 검증을 준비한다.
2. 네 등급 탭, 알 뽑기·공개, 입력 검증, 애니메이션, 로컬 저장 기능을 구현한다.
3. lint, TypeScript, 단위 테스트, 프로덕션 빌드를 실행한다.
4. 데스크톱과 모바일에서 탭·입력·알 공개·새로고침 복원·기록·반응형 화면을 검토한다.
5. 검증한 변경을 기존 Vercel 사이트에 재배포하고 공개 페이지 결과를 별도로 확인한다.

## 수용 기준

- 상 60%, 중 35%, 하 4.9%, 극하 0.1%와 각 등급 내 균등 선택이 결정적 경계 테스트를 통과한다.
- 네 탭에서 텍스트 항목을 편집할 수 있고 등급에 맞는 알과 벌칙이 표시된다.
- 빈 등급·소진 등급에서 고정 확률을 바꾸지 않으며 복구 동작을 제공한다.
- 새로고침으로 대기 알을 바꾸거나 기록을 중복 추가하지 않는다. 기존 사용자 항목과 기록을 유지한다.
- 모바일 화면에서 핵심 동작을 가로 스크롤 없이 사용할 수 있다.
- `quality_gates.yaml`의 필수 자동 검증을 통과하고 빌드 산출물 `dist`가 생성된다.
- 실제 수행한 검증만 완료로 기록한다. 비밀 값과 개인 계정 데이터는 읽거나 저장하지 않는다.
